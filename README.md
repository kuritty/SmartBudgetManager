# README

**SmartBudget Manager — Personal Finance & Monthly Budget Tracking Workbook**

(SmartBudget_Manager.xlsx)

## 1. About

SmartBudget Manager is an easy-to-use Excel workbook designed to help users record monthly income and expenses, categorize spending, calculate monthly balances automatically, and visualize financial habits through built-in charts and overspending alerts.

## 2. Prerequisites

To open and use this workbook properly, ensure you have one of the following compatible applications installed:

- Microsoft Excel 2016, 2019, 2021, or Microsoft 365
- An equivalent compatible spreadsheet application supporting SUMIF / SUMIFS formulas, charts, and conditional formatting.

## 3. Workbook Structure

The workbook is organized into three dedicated worksheets:

| Worksheet | Purpose |
|---|---|
| Dashboard | Displays the monthly balance, total income, total expenses, budget warnings, and visual summary charts. |
| Transactions | Dedicated table for entering and tracking daily income and expense entries with dates and descriptions. |
| Categories | Contains predefined expense categories such as Food, Transport, Rent, Health, and Education. |

## 4. Getting Started

1. Locate and open the SmartBudget_Manager.xlsx file in Microsoft Excel.
2. Navigate to the Transactions worksheet and select the first empty row in the table.
3. Enter the transaction date, description, category, and amount in either the Income or Expense column.
4. Switch to the Dashboard worksheet to review your automatically updated monthly balance, category chart, and budget limit status.

**Important Note:** Avoid editing or deleting cells containing formulas (such as totals on the Dashboard) to preserve automatic calculations.
